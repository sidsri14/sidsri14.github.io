Active Configuration Rules

MC001: Unpinned Package in Command Arguments [HIGH]
Flags unversioned npx / uvx / pip package invocations that automatically download latest code at runtime.
Remediation: Pin packages to exact semver (e.g. @modelcontextprotocol/server-postgres@0.1.2).
MC002: Hardcoded Plaintext Secret in Environment [HIGH]
Detects committed API keys, tokens, and database passwords in the env block.
Remediation: Replace with environment variable expansion references like "${DB_PASSWORD}".
MC003: Insecure Cleartext Endpoint [HIGH]
Flags remote MCP servers configured over plain http:// or ws:// protocols.
Remediation: Always use TLS-encrypted https:// or wss:// endpoints.
MC004: Dangerous Flag in Server Arguments [MEDIUM]
Detects blanket permission bypass flags like --dangerously-skip-permissions.
Remediation: Remove blanket bypass flags; scope access per folder.
