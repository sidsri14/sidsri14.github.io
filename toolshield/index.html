Active Security Rules & Diagnostic Coverage

TS001: Tool Poisoning Prompt Injection [HIGH]
Detects imperative override instructions embedded in tool descriptions aimed at hijacking LLM behaviors.
Remediation: Rewrite as neutral capability statement; strip override clauses.
TS002: Invisible Unicode Control Characters [HIGH]
Flags zero-width spaces (\u200B), joiners, and bidi overrides hiding malicious text from human reviewers.
Remediation: Strip all non-printable and invisible Unicode code points.
TS003: Credential / Secret in Input Schema [HIGH]
Prevents API keys, passwords, and tokens from being declared as tool input arguments, which risk LLM chat log leakage.
Remediation: Store credentials in secure backend vaults and pass opaque session references.
TS004: Unbounded additionalProperties [MEDIUM]
Catches open schemas that permit arbitrary prompt-injection payload fields.
Remediation: Explicitly declare additionalProperties: false.
